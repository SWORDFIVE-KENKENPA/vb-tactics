# バレーボール戦術分析（PWA版）

iPadのホーム画面に追加して、オフラインでも起動できるWebアプリです。

## フォルダの中身

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体 |
| manifest.webmanifest | アプリ名・アイコン・横向き表示などの設定 |
| sw.js | オフライン用にファイルを端末へ保存する仕組み（Service Worker） |
| icon-*.png / apple-touch-icon.png | ホーム画面用アイコン |

## 1. Webサーバーに置く（HTTPSが必須）

PWAは **https:// で始まるURL** に置いたときだけ動作します。
ファイルをダブルクリックして開いた場合は、オフライン機能が働きません（記録はできます）。

**GitHub Pages を使う例（無料）**
1. GitHubで新しいリポジトリを作る（例：vb-tactics）
2. このフォルダの中のファイルをすべてアップロードする（フォルダごとではなく中身を）
3. Settings → Pages → Branch を「main」「/(root)」にして Save
4. 数分後に表示される `https://（ユーザー名）.github.io/vb-tactics/` がアプリのURL

HTTPS対応の校内サーバーがあれば、そこにファイル一式を置いても構いません。

## 2. iPadにインストールする

1. iPadの **Safari** でアプリのURLを開く（ネットにつながった状態で）
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから一度起動する（ここでオフライン用のデータが保存されます）
4. 以後は機内モードでも起動・記録できます

## 3. 注意点

- **データは端末ごと・起動方法ごとに別々に保存されます。** Safariで開いた場合とホーム画面のアイコンから開いた場合でもデータは共有されないため、ふだんは必ずホーム画面のアイコンから起動してください。
- アプリのURLを変えると、それまでの記録は見えなくなります。移す前に「試合・選手設定」→「JSONで書き出し」で保存し、新しいURLで読み込んでください。
- 大切な試合のあとは、JSONでバックアップを取ることをおすすめします。

## 4. アプリを更新するとき

1. 新しい index.html でサーバー上のファイルを置き換える
2. sw.js の `const CACHE = 'vb-tactics-v3';` の番号を1つ上げる（v3 → v4）
3. iPadでネットにつながった状態でアプリを開き、「新しいバージョンがあります」と表示されたら一度閉じて開き直す

記録したデータは更新しても消えません。
